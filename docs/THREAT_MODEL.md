# Trust boundaries

A browser may submit arbitrary fields, retry a transaction or present a link from another shop. The server selects the tenant from a random hashed session cookie. Customer capability tokens grant one scoped statement, expire and can be revoked. JSON writes require a custom header and same-origin browser context. Journals record one positive integer amount and two distinct account identifiers as a balanced pair. Database triggers reject edits and deletions. A reversal is another pair in the opposite direction. Dispute notes and uploaded narration are untrusted text. The UI inserts them as text. CSV exports neutralize formula prefixes. Keys and capability tokens stay out of logs. Synthetic data only. Host administrators can replace the entire SQLite file and its audit chain. Anyone with a customer link may attest as its bearer.
