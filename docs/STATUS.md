# Release status · 24 November 2026

The public demo, repository and automated checks are operational. The implemented slice covers paired journals, reversals, period close, idempotency, customer attestation and dispute, delegated staff and accountant roles, audit chaining, form and phrase proposals, a draft-only model adapter, CSV reconciliation, financial reports and printable sample invoices.

The deployment is a single same-origin Node service on Render Free with SQLite. MongoDB runs in an integration test against a real replica set. It is optional in the application and has not been provisioned on Atlas. Public visitors receive a writable isolated synthetic shop.

Public demo: https://khata-folio.onrender.com/
