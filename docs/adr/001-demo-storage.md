# Ship an isolated demo on one free service

Use Node 22, Express, SQLite transactions and a same-origin browser client. Each visitor opens a separate synthetic shop. A capability link grants one customer statement and its attestations. Prepared statements scope every write to a shop. The demo needs no identity provider, cloud database or language-model credential. SQLite on Render's ephemeral filesystem makes this a disposable demonstration. A durable MongoDB replica set, verified identities, managed roles and an encrypted backup/restore workflow remain separate release gates.
